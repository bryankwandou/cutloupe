MCP server for Claude Code, Antigravity, Codex and other agents. Runs on Windows, macOS and Linux.

A video editor your agent can see.

Cutloupe gives your agent a real timeline. It cuts, titles, captions and scores the video while you watch each edit land in the studio. Before it says the job is done, it renders the actual frames and looks at them.

00:00:12:00How it works

Edit, show, look, fix.

Most agent video tools write a file and hope. Cutloupe closes the loop, so the agent finds its own mistakes before you have to.

  1. 01

    The agent edits

    Each call, like add_text or split_clip, becomes an operation on one shared timeline. Batches apply all at once or not at all, and every step can be undone.

    add_text("Cutloupe", start 0.4)
  2. 02

    You watch it land

    The studio redraws on the next frame. Clips the agent touched light up in amber with a note saying what changed. Your own edits show in blue, and the agent sees them too.

    studio ← op · 16 ms
  3. 03

    The agent looks

    The look tool renders frames with the same compositor the MP4 export uses, then returns an image and a list of everything on screen. You see where it looked.

    look(times: [1.5, 2.5])
  4. 04

    It fixes what it finds

    If a subtitle sits on top of a title, the agent notices, moves it, and checks again. The demo above makes that exact mistake on purpose at 2.5 seconds.

    edit_clip(sub, y 0.55 → 0.68)

00:00:48:00Captions

Captions from a file, a subtitle track, or speech.

extract_captions reads an .srt or .vtt file, or the first subtitle stream inside the video. If neither exists and Whisper is installed on your machine, it transcribes the audio locally. Words get their own timings either way.

    00:01:36:00Edit ledger · Solana devnet

    A receipt that points at the exact cut.

    Optional. With a devnet keypair set, the ledger tool writes the timeline's hash to a reel account, then seals the exported file's SHA-256 against that head. A seal can only be written for the current head, so it always names the cut that produced the file.

    Each seal also says whether the edit was done by an agent, a person or both, and whether the media or voice is synthetic. Anyone can check a file by hashing it. Try it with any file: nothing is uploaded.

    00:01:48:00Install
    
    
    Five minutes to the first cut.
    
    
    You need Node 20 or newer, ffmpeg on your PATH, and Chrome or Edge for rendering. Build once, then point your agent at the server.
    
    
    # 1 · build
git clone https://github.com/bryankwandou/cutloupe
cd cutloupe
npm install
npm run build
    
    
    
      
      
      
      
    
    
    
    # 2 · register the server (run inside the cutloupe folder)
claude mcp add cutloupe -- node "$PWD/packages/mcp/bin/cutloupe.mjs"
    
    
    // 2 · Agent panel → MCP servers → Manage → View raw config (mcp_config.json)
{
  "mcpServers": {
    "cutloupe": {
      "command": "node",
      "args": ["C:/path/to/cutloupe/packages/mcp/bin/cutloupe.mjs"]
    }
  }
}
    
    
    # 2 · ~/.codex/config.toml
[mcp_servers.cutloupe]
command = "node"
args = ["C:/path/to/cutloupe/packages/mcp/bin/cutloupe.mjs"]
    
    
    // 2 · any client that reads an mcpServers block over stdio
{
  "mcpServers": {
    "cutloupe": { "command": "node", "args": ["/path/to/cutloupe/packages/mcp/bin/cutloupe.mjs"] }
  }
}
    
    
    Then ask for something like Make a 20-second vertical teaser from intro.mp4 with bold captions and calm music, and check it before you export. The studio opens at 127.0.0.1:4321 on the first edit.
    
    
    
      Environment variables
      
    
        
    CUTLOUPE_PORT
    Studio port. Default 4321; the next free port is used if it is taken.
    
        
    CUTLOUPE_HOME
    Where projects, music and exports go. Default ~/.cutloupe.
    
        
    CUTLOUPE_NO_OPEN
    Set to 1 to stop the studio opening in your browser.
    
        
    CUTLOUPE_CHROME
    Path to Chrome or Edge, if it is not in the usual place.
    
        
    CUTLOUPE_KEYPAIR
    A devnet keypair file. Turns on the edit ledger.
    
        
    CUTLOUPE_WHISPER_MODEL
    Whisper model name, or a ggml file for whisper.cpp.
    
      
    
    
    
  
    

    



    
  
    
    
    00:02:00:00Limits
    
    
    What it does not do yet.
    
    
      
      
    • It does not generate footage. It edits and animates what you give it, and adds titles, shapes, captions and music.
      • 
      
    • Speech-to-text needs Whisper installed locally. Without it, captions come from subtitle files or tracks.
      • 
      
    • The FCPXML, Premiere and CapCut exports pass structural tests, but we have not yet opened them in Resolve, Premiere or CapCut on this release.
      • 
      
    • MP4 export renders every frame through headless Chrome. On our test machine an 8-second 1080p reel took about two and a half minutes.
      • 
      
    • The npm package is not published yet, so install from GitHub for now.
      • 
    
    
  
    

    



    
  
    
    
    00:02:12:00Questions
    
    
    Questions people ask first.
    
    
    
      
    How is this different from asking an agent to write an ffmpeg command?
    An ffmpeg command is a guess the agent cannot check. Here the agent works on a timeline it can read back, sees rendered frames, and you can step in at any moment without breaking its plan.
    
      
    Can I edit while the agent is working?
    Yes. Drag, trim or delete in the studio. Your edits go through the same operation log, the agent sees them on its next call, and undo covers both of you.
    
      
    Does my footage leave my machine?
    No. The server, the studio and the renderer all run on 127.0.0.1. The only network call is the optional ledger, which sends hashes, never media.
    
      
    Why Solana, and do I need it?
    You do not need it. The ledger exists for people who publish edited or AI-assisted video and want a public, cheap record of which cut produced which file. It runs on devnet today.
    
      
    What does it cost?
    Nothing. Cutloupe is MIT-licensed, and the music library is CC0.
